# 位运算 · 一页笔记（易错点清单）

> 嵌入式软开 · 阶段0 第1天（2026-08-06）｜ 来源：DeepSeek 分享对话精华整理

## 一、六种位运算速查

| 运算符 | 名称 | 规则 | 例子（8位） |
| --- | --- | --- | --- |
| `&` | 按位与 | 两个位都是 1，结果才是 1 | `5 & 3` = 1 |
| `\|` | 按位或 | 有一个是 1 就为 1 | `5 \| 3` = 7 |
| `^` | 按位异或 | 相同为 0，不同为 1 | `5 ^ 3` = 6 |
| `~` | 按位取反 | 0↔1（补码，含符号位） | `~5` = -6，口诀 `~x = -(x+1)` |
| `<<` | 左移 | 高位丢、低位补 0，等于 ×2^n | `5<<1` = 10 |
| `>>` | 右移 | 低位丢、**高位补符号位** | `-5>>1` = -3 |

## 二、优先级（背口诀 + 加括号）

- 常见完整阶梯（从高到低）：
  `~`(单目) > `* /` > `+ -` > `<< >>` > 关系(`< <= > >=`) > 相等(`== !=`) > `&` > `^` > `|` > 逻辑(`&&`、`||`) > 赋值(`=`)
- 三句重点：
  1. 位运算整体 **低于** 算术、移位、关系、比较（`== !=`）
  2. 位运算内部：**`&` > `^` > `|`**
  3. 位运算 **高于** 逻辑（`&&`、`||`）和赋值
- ⚠️ 陷阱：`a & 3 == 1` → 因为 `==` 比 `&` 更优先 → 实际是 `a & (3 == 1)` → 永远 0
- 铁律：**位运算一律加括号** `(a & 3) == 1`

## 三、掩码四大操作（MASK = `1<<2`）

```c
REG |= MASK;      // 置1
REG &= ~MASK;     // 清0
REG ^= MASK;      // 翻转
if (REG & MASK)   // 读取（不影响原值）
// 多字段（先清后置）：
REG = (REG & ~(0x3 << 3)) | (value << 3);
```

## 四、为什么寄存器操作用位运算

1. **原子性**：位操作在汇编层接近单条指令，读-改-写窗口短，防中断破坏
2. **非破坏性**：只改目标位，不误伤相邻的独立开关位
3. **高效**：无除法器、无分支
> 不是为省内存！寄存器每一位 = 一个独立硬件功能开关。

## 五、进制与位编号

- 1 位十六进制 = 4 位二进制（8421 拆解：`0x3A` = `0011 1010`）
- 特殊值速记：`A=1010`、`5=0101`、`F=1111`、`0=0000`
- **位编号从 0 起**：手册写 Bit5 → 写 `1<<5` = `0x20`（物理上是第 6 位）
- `0x7` = 低 3 位全 1；`(0x7<<5)` = `0xE0`（**不是** 0x70）
- `0x7` 和 `0x07` 数值完全相同，前导 0 只影响可读性
- 操作连续位套路：数几个 1 → 写成 `0x7` → 左移对齐 `(0x7 << 5)`

## 六、嵌入式类型速记

- `uint8_t` 底层就是 `unsigned char` 的“马甲”，名字里的数字 = 位数
- 常用全家桶：`uint8_t` / `uint16_t` / `uint32_t` / `int32_t` / `bool` / `float`
- 为什么少用 `int`：字节数随编译器变（16 位机 `int`=2 字节），带数字的类型**固定**
- 还会看到 `char`：字符串、标准库函数（`memcpy`/`strlen`）、历史代码
- `_t` = type 后缀，`stdint.h` 里 `typedef` 的命名规范

## 七、易错点清单（考前必扫）

1. **`#define MASK 0011` → 0 开头 = 八进制 → 十进制 9！** 要写 `0x03` 或 `0b0011`
2. `a & 3 == 1` → `==` 先算 → 永远 0；写 `(a & 3) == 1`
3. `0b` 不是标准 C（GCC/Keil/IAR 扩展，C23 才转正）；考试/正式代码用 `0x`
4. Bit5 = `1<<5` = `0x20` = 物理第 6 位（**别写 `1<<6`**）
5. `(0x7<<5)` = `0xE0`，不是 `0x70`
6. `~` 是补码取反：`~5` = -6（口诀 `~x = -(x+1)`）
7. 右移负数高位补 1：`-5>>1` = -3（向下取整）
8. `^=` 优先级垫底，**独占一行**；要新变量用 `int c = a ^ b;`
9. `REG |=` 是“读-改-写”三条指令，可能被中断破坏
10. **外设先开时钟再操作寄存器**，否则写了也不动

## 八、必背代码模板

```c
#define SET_BIT(reg, bit)     ((reg) |= (1 << (bit)))
#define CLEAR_BIT(reg, bit)   ((reg) &= ~(1 << (bit)))
#define TOGGLE_BIT(reg, bit)  ((reg) ^= (1 << (bit)))
#define READ_BIT(reg, bit)    (((reg) >> (bit)) & 1)

// 判断奇偶
if (n & 1) { ... }
// 交换两数（面试向）
a ^= b; b ^= a; a ^= b;
// 判断 2 的幂
if ((n > 0) && ((n & (n - 1)) == 0)) { ... }
// 统计二进制中 1 的个数（两种写法）
int cnt = 0; while (n) { n &= (n - 1); cnt++; }   // 每次消掉最低位的 1
int cnt2 = 0; for (; n; n >>= 1) cnt2 += (n & 1); // 逐位检查
```
