# 位运算一页速记（2026-08-06 考前扫一眼）

做题之前先念三遍：**位运算一律加括号**。

## 六个运算符

| 运算符 | 规则 | 例子 |
|--------|------|------|
| & 与 | 都是 1 才是 1 | 5 & 3 = 1 |
| \| 或 | 有 1 就 1 | 5 \| 3 = 7 |
| ^ 异或 | 相同 0 不同 1 | 5 ^ 3 = 6 |
| ~ 取反 | 0↔1（补码） | ~5 = -6，口诀 ~x = -(x+1) |
| << 左移 | 低位补 0，×2^n | 5<<1 = 10 |
| >> 右移 | 高位补符号位 | -5>>1 = -3 |

## 优先级

`~` > `* /` > `+ -` > `<< >>` > 关系 > `== !=` > `&` > `^` > `|` > `&& ||` > `=`

三句重点：
1. 位运算低于算术、移位、关系、相等
2. 内部 `&` > `^` > `|`
3. 高于逻辑和赋值

陷阱：`a & 3 == 1` 永远 0，== 先算。要写 `(a & 3) == 1`。

## 掩码（MASK = 1<<2）

```c
REG |= MASK;      // 置 1
REG &= ~MASK;     // 清 0
REG ^= MASK;      // 翻转
if (REG & MASK)   // 读
// 多字段先清后置：
REG = (REG & ~(0x3 << 3)) | (value << 3);
```

## 为什么寄存器用位运算

- 读-改-写窗口短，防中断
- 只动目标位，不误伤
- 无除法、无分支

不是省内存，每一位是独立开关。

## 进制和位编号

- 1 位十六进制 = 4 位二进制，0x3A = 0011 1010
- 特殊值：A=1010、5=0101、F=1111、0=0000
- 位编号从 0 开始：Bit5 = `1<<5` = 0x20（物理第 6 位）
- `0x7` = 低 3 位全 1；`(0x7<<5)` = 0xE0，不是 0x70
- 连续位套路：数几个 1 → 写成 0x7 → 左移对齐 `(0x7 << 5)`

## 类型

uint8_t 就是 unsigned char 的马甲，数字 = 位数。带数字的类型固定，int 随平台变（16 位机 2 字节）。
`_t` 是 stdint.h 里 typedef 的命名后缀。

## 易错点清单

1. `#define MASK 0011` = 八进制 = 十进制 9！写 0x03 或 0b0011
2. `a & 3 == 1` 永远 0，== 先算
3. `0b` 不是标准 C（C23 才转正），写 0x
4. Bit5 = `1<<5` = 0x20，别写 1<<6
5. `(0x7<<5)` = 0xE0，不是 0x70
6. `~5` = -6
7. `-5>>1` = -3，负数右移补 1
8. `^=` 优先级垫底，独占一行；要新值用 `int c = a ^ b;`
9. `REG |=` 会被中断打断
10. 先开外设时钟，再操作寄存器

## 背下来

```c
#define SET_BIT(reg, bit)     ((reg) |= (1 << (bit)))
#define CLEAR_BIT(reg, bit)   ((reg) &= ~(1 << (bit)))
#define TOGGLE_BIT(reg, bit)  ((reg) ^= (1 << (bit)))
#define READ_BIT(reg, bit)    (((reg) >> (bit)) & 1)
```

- 判断奇偶：`if (n & 1)`
- 交换：`a ^= b; b ^= a; a ^= b;`
- 2 的幂：`if ((n > 0) && ((n & (n - 1)) == 0))`
- 数 1：`while (n) { n &= (n - 1); cnt++; }`（每次消掉最低位那个 1）
