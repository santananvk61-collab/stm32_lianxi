今天是 C 语言收尾阶段的第 1 天，原计划一个下午搞定位运算，实际拖到晚上才把笔记整理完。内容本身不难，就是细节多，尤其优先级特别容易踩坑。

## 六种运算符

| 运算符 | 名称 | 规则 | 例子 |
|--------|------|------|------|
| & | 按位与 | 两个位都是 1 才是 1 | 5 & 3 = 1 |
| \| | 按位或 | 有一个是 1 就是 1 | 5 \| 3 = 7 |
| ^ | 按位异或 | 相同为 0，不同为 1 | 5 ^ 3 = 6 |
| ~ | 按位取反 | 0 变 1、1 变 0（补码） | ~5 = -6 |
| << | 左移 | 高位丢掉，低位补 0，等于乘 2^n | 5<<1 = 10 |
| >> | 右移 | 低位丢掉，高位补符号位 | -5>>1 = -3 |

右移负数高位补 1（算术右移），相当于向下取整。-5>>1 = -3 就是 -2.5 向下取整的结果。

## 优先级，重点中的重点

从高到低大概是：`~`（单目）> 乘除 > 加减 > 移位 > 关系 > 相等（== !=）> `&` > `^` > `|` > 逻辑（&& ||）> 赋值

记三件事就行：
1. 位运算整体比算术、移位、关系、相等比较都低
2. 位运算内部 `&` > `^` > `|`
3. 位运算比逻辑运算和赋值高

最容易错的例子：`a & 3 == 1` 这种写法，因为 == 比 & 优先，实际算的是 `a & (3 == 1)`，而 (3==1) 是 0，结果永远为 0。
所以写位运算一律加括号，别偷懒。

## 掩码

以 MASK = `1<<2` 为例：

```c
REG |= MASK;      // 置 1
REG &= ~MASK;     // 清 0
REG ^= MASK;      // 翻转
if (REG & MASK)   // 读这一位
```

多字段就是先清后置：

```c
REG = (REG & ~(0x3 << 3)) | (value << 3);
```

## 为什么寄存器操作用位运算

1. 接近单条指令，读-改-写窗口短，不容易被中断打断
2. 只动目标位，不碰旁边那些独立的开关位
3. 没有除法、没有分支，快

注意：不是为了省内存。寄存器每一位就是一个独立的功能开关，整体赋值会误关别的外设。

## 为什么用宏不用函数

1. 编译期展开，没有调用开销，不压栈不跳转
2. 类型通用，uint8_t / uint16_t / uint32_t 都能用，C 又没有函数重载
3. 能直接操作寄存器这种左值，比如 SET_BIT(GPIOA->ODR, 5)

缺点：没有类型检查，参数会重复求值，所以传参尽量用变量。

## 宏为什么要加那么多括号

宏就是文本替换，编译器不知道边界在哪。SQR(2+3) 不加括号会变成 2+3*2+3：

```c
#define SET_BIT(reg, bit)  ((reg) |= (1 << (bit)))
```

(bit) 防止 2+3 这种表达式被拆开，(reg) 防止 a|b 这种复合表达式语法错乱，最外层的整体括号让宏能当做一个值参与周围表达式。

## 为什么只动目标位

- 或：掩码是 1 的位置置 1，0 的位置不变（0|x = x）
- 与反码：掩码是 0 的位置清 0，1 的位置不变（1&x = x）
- 异或：1 翻转，0 不变

## 补码

最高位是负的权重，8 位时 MSB = -128。1111 1010 当无符号看是 250，当有符号看就是 250 - 256 = -6。口诀：~x = -(x+1)。

## 类型

uint8_t 底层就是 unsigned char，名字里的数字就是位数。常用 uint8_t / uint16_t / uint32_t / int32_t / bool / float。
int 的字节数跟平台走（16 位机是 2 字节），带数字的类型是固定的。_t 是 type 后缀，stdint.h 里 typedef 的命名规范。

## 易错点

1. `#define MASK 0011` —— 0 开头是八进制！等于十进制 9，要写 0x03 或 0b0011
2. `a & 3 == 1` —— == 先算，结果永远 0，要写 `(a & 3) == 1`
3. `0b` 不是标准 C（GCC/Keil 的扩展，C23 才转正），考试和正式代码写 0x
4. 手册写 Bit5 就是 `1<<5` = 0x20，物理上是第 6 位，别写 1<<6
5. `(0x7<<5)` = 0xE0，不是 0x70
6. `~5` = -6
7. `-5>>1` = -3，负数右移高位补 1
8. `^=` 优先级垫底，独占一行；要新值就 int c = a ^ b;
9. `REG |=` 是读-改-写三条指令，可能被中断破坏
10. 外设先开时钟再操作寄存器，不然写了也白写

## 今天写的代码

4 个宏：

```c
#define SET_BIT(reg, bit)     ((reg) |= (1 << (bit)))
#define CLEAR_BIT(reg, bit)   ((reg) &= ~(1 << (bit)))
#define TOGGLE_BIT(reg, bit)  ((reg) ^= (1 << (bit)))
#define READ_BIT(reg, bit)    (((reg) >> (bit)) & 1U)
```

16 位寄存器模拟，验证只动目标位：

```c
uint16_t REG = 0x0000;
SET_BIT(REG, 3);    // 0x0008
SET_BIT(REG, 7);    // 0x0088，bit3 没被碰
CLEAR_BIT(REG, 3);  // 0x0080
TOGGLE_BIT(REG, 0); // 0x0081
TOGGLE_BIT(REG, 0); // 0x0080，异或两次还原
READ_BIT(REG, 7);   // 1
```

3 道题：

```c
// 数 1 的个数，n &= (n-1) 每次消掉最低位的那个 1
int count_ones(uint32_t n) {
    int cnt = 0;
    while (n) { n &= (n - 1); cnt++; }
    return cnt;
}

// 判断 2 的幂
int is_power_of_two(int n) {
    return (n > 0) && ((n & (n - 1)) == 0);
}

// 异或交换，注意 a、b 是同一个变量时会变成 0
void swap(int *a, int *b) {
    *a ^= *b; *b ^= *a; *a ^= *b;
}
```

综合题是写一个寄存器组管理器：结构体 Reg8{name, value} + 数组 + 函数传指针 + 位运算，实现 reg_set_bit / reg_clear_bit / reg_toggle_bit / reg_read_bit 四个函数。这里复习了数组名传参会退化成指针、const 只读保护、sizeof(Reg8) 在 32 位平台是 8 字节、64 位平台是 16 字节（平台相关）。4 个寄存器操作完，1 的总数是 15（0+3+4+8）。
