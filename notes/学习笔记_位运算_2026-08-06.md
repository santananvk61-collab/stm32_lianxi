## 二、核心知识点

### 1. 六种位运算速查

| 运算符 | 名称 | 规则 | 例子 |
| --- | --- | --- | --- |
| `&` | 按位与 | 都是 1 才是 1 | `5 & 3` = 1 |
| `\|` | 按位或 | 有 1 即 1 | `5 \| 3` = 7 |
| `^` | 按位异或 | 相同为 0、不同为 1 | `5 ^ 3` = 6 |
| `~` | 按位取反 | 0↔1（补码） | `~5` = -6 |
| `<<` | 左移 | 高位丢、低位补 0，×2^n | `5<<1` = 10 |
| `>>` | 右移 | 低位丢、高位补符号位 | `-5>>1` = -3 |

### 2. 优先级（重点！）

完整阶梯（从高到低）：`~`(单目) > `* /` > `+ -` > `<< >>` > 关系(`< <= > >=`) > 相等(`== !=`) > `&` > `^` > `\|` > 逻辑(`&&` `||`) > 赋值(`=`)

- 位运算整体 **低于** 算术、移位、关系、比较；位运算内部 **`&` > `^` > `\|`**；位运算 **高于** 逻辑和赋值
- ⚠️ 陷阱：`a & 3 == 1` → `==` 比 `&` 更优先 → 实际是 `a & (3==1)` → 永远 0
- 铁律：**位运算一律加括号**

### 3. 掩码四大操作（MASK = `1<<2`）

```c
REG |= MASK;      // 置1
REG &= ~MASK;     // 清0
REG ^= MASK;      // 翻转
if (REG & MASK)   // 读取
// 多字段（先清后置）：
REG = (REG & ~(0x3 << 3)) | (value << 3);
```

### 4. 为什么寄存器操作用位运算

1. **原子性**：位操作接近单条指令，读-改-写窗口短，防中断破坏
2. **非破坏性**：只改目标位，不误伤相邻的独立开关位
3. **高效**：无除法器、无分支
> 不是为省内存！寄存器每一位 = 一个独立硬件功能开关

### 5. 为什么用宏不用函数

1. **无调用开销**：编译期原地展开，无压栈/跳转/返回
2. **类型通用**：`uint8_t`/`uint16_t`/`uint32_t` 通吃（C 无函数重载）
3. **直接操作寄存器地址/左值**：如 `SET_BIT(GPIOA->ODR, 5)`
- 缺点：无类型检查、参数重复求值（传参只用变量）

### 6. 为什么宏处处加括号

宏是文本替换，编译器不知道宏的边界。三处都要：
```c
#define SET_BIT(reg, bit)  ((reg) |= (1 << (bit)))
```
- `(bit)`：防 `2+3` 这类表达式被拆开
- `(reg)`：防复合表达式（如 `a|b`）语法错乱
- 整体括号：让宏当作一个“值”参与周围表达式

### 7. 为什么只动目标位（非破坏性）

- 或：掩码 1 的位置置 1，0 的位置不变（`0|x=x`）
- 与反码：掩码 0 的位置清 0，1 的位置不变（`1&x=x`）
- 异或：1 翻转、0 不变
- 寄存器每一位是独立开关，整体赋值会误关其他外设 → 必须“读-改-写”

### 8. 补码速记

- 最高位(MSB)权重是 **负的**：8 位时 MSB = -128
- `1111 1010` = 无符号 250 → 有符号 250-256 = **-6**
- 口诀：`~x = -(x+1)`；负数右移高位补 1（算术右移，向下取整）

### 9. 类型补充

- `uint8_t` 底层就是 `unsigned char` 的“马甲”，名字里的数字 = 位数
- 常用：`uint8_t` / `uint16_t` / `uint32_t` / `int32_t` / `bool` / `float`
- `int` 字节数随平台变（16 位机=2 字节），带数字的类型固定
- `_t` = type 后缀（`stdint.h` 的 typedef 命名规范）

## 三、易错点清单（10 条）

1. `#define MASK 0011` → **0 开头 = 八进制 = 十进制 9！** 要写 `0x03` / `0b0011`
2. `a & 3 == 1` → `==` 先算 → 永远 0
3. `0b` 不是标准 C（GCC/Keil 扩展，C23 转正）；考试用 `0x`
4. 手册 Bit5 = `1<<5` = `0x20` = 物理第 6 位（别写 `1<<6`）
5. `(0x7<<5)` = `0xE0`，不是 `0x70`
6. `~5` = -6；`-5>>1` = -3
7. `^=` 优先级垫底，独占一行
8. `REG |=` 是“读-改-写”三条指令，可能被中断破坏
9. 外设先开时钟再操作寄存器
10. `sizeof` 是平台相关的（指针大小不同 → 结构体大小不同）

#define SET_BIT(reg, bit)     ((reg) |= (1 << (bit)))

### 16 位寄存器模拟（验证“只动目标位”）
```c
uint16_t REG = 0x0000;
SET_BIT(REG, 3);    // 0x0008
SET_BIT(REG, 7);    // 0x0088（bit3 没被碰）
CLEAR_BIT(REG, 3);  // 0x0080
TOGGLE_BIT(REG, 0); // 0x0081
TOGGLE_BIT(REG, 0); // 0x0080（异或两次还原）
READ_BIT(REG, 7);   // 1
```

### 3 道位运算题
```c
// ① 统计 1 的个数
int count_ones(uint32_t n) {
    int cnt = 0;
    while (n) { n &= (n - 1); cnt++; }   // 进阶：循环次数 = 1 的个数
    return cnt;
}
// ② 判断 2 的幂
int is_power_of_two(int n) {
    return (n > 0) && ((n & (n - 1)) == 0);
}
// ③ 异或交换
void swap(int *a, int *b) {
    *a ^= *b; *b ^= *a; *a ^= *b;   // 注意：同一变量会变 0
}
```
