# 智能小车控制系统（循迹 + 蓝牙遥控）

课程设计：STM32F103C8T6（Blue Pill）为主控，实现小车的**自动循迹**和**手机蓝牙遥控**两种模式。

## 硬件清单

| 模块 | 型号 | 数量 |
|------|------|------|
| 主控 | STM32F103C8T6 最小系统板 | 1 |
| 电机驱动 | L298N | 1 |
| 直流减速电机 | 带轮子 | 2（左右各一） |
| 循迹传感器 | TCRT5000（4 路） | 4 |
| 蓝牙模块 | HC-05 | 1 |
| 供电 | 电池（7.4V 接 L298N 电源，5V 给板子） | 1 |

## 接线表

| 引脚 | 接到 |
|------|------|
| PA0 / PA1 / PA2 / PA3 | 循迹传感器（左外/左内/右内/右外）的信号脚 DO |
| PA4 / PA5 | L298N 左轮 IN1 / IN2 |
| PB0 / PB1 | L298N 右轮 IN3 / IN4 |
| PA6 | L298N 左轮 ENA（PWM） |
| PA7 | L298N 右轮 ENB（PWM） |
| PA9（TX）/ PA10（RX） | HC-05 的 RX / TX（**交叉接**，TX 接 RX） |
| 5V / GND | 所有模块共地 |

> 注意：HC-05 默认波特率 9600，代码里就是这么配的。如果手机上连不上，先用 AT 指令确认波特率。

## 两种模式

- **循迹模式**：上电默认。4 路 TCRT5000 检测黑线，算偏差后用 PID（其实主要是 P）修正左右轮差速，让车压着线走。
- **蓝牙模式**：收到任意蓝牙指令后自动切换过去；按手机 App 的按键控制方向；发 `A` 切回循迹。

## 蓝牙指令表

| 字符 | 动作 |
|------|------|
| F / f | 前进 |
| B / b | 后退 |
| L / l | 左转 |
| R / r | 右转 |
| S / s | 停止 |
| A / a | 切回自动循迹 |

手机上装个「蓝牙串口助手」之类的 App，连接 HC-05 后发单字符即可。

## 调试笔记（踩过的坑）

1. **上电电机乱转**：GPIO 初始化时先把 IN1~IN4 全部拉低再配输出，否则初始化瞬间电平不确定。
2. **循迹方向反了**：如果车往线的反方向转，可能是左右轮接线反了，或者把 `motor.c` 里 `Motor_Left`/`Motor_Right` 的正负号对调一下。
3. **压黑线电平反了**：不同 TCRT5000 模块输出极性不一样。代码里 `main.h` 有个 `TRACK_ON_LINE_LEVEL` 宏，压线是低电平就保持 `GPIO_PIN_RESET`，是高点平就改成 `GPIO_PIN_SET`。
4. **蓝牙收不到**：检查 TX/RX 是不是交叉接，波特率是不是 9600，共地了没。
5. **速度别调太高**：`BASE_SPEED` 默认 55，调太高弯道容易冲出去。

## 代码结构

```
Core/Src/main.c          主逻辑（模式切换）
Core/Src/motor.c         电机驱动（PWM 调速 + 正反转）
Core/Src/tracking.c      循迹（读传感器 + PID 修正）
Core/Src/bluetooth.c     蓝牙（串口中断收指令 + 解析）
Core/Src/pid.c           简易 PID
Core/Src/tim.c           TIM3 两路 PWM（1kHz）
Core/Src/usart.c         USART1（9600）
```
