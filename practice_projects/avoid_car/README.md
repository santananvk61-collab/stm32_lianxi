# 四轮自动避障小车

课程设计：STM32F103C8T6（Blue Pill）为主控，超声波测距 + 差速转向，实现小车在复杂障碍环境下的自主避障行驶。

## 硬件清单

| 模块 | 型号 | 数量 |
|------|------|------|
| 主控 | STM32F103C8T6 最小系统板 | 1 |
| 电机驱动 | L298N | 1 |
| 直流减速电机 | 带轮子 | 2（左右各一，驱动四轮） |
| 超声波传感器 | HC-SR04 | 1 |
| 供电 | 电池（7.4V 给 L298N，5V 给板子） | 1 |

> 四轮车一般用 2 个电机：左边 2 个轮子并一起接左路，右边 2 个轮子并一起接右路，靠差速转向。

## 接线表

| 引脚 | 接到 |
|------|------|
| PA4 / PA5 | L298N 左轮 IN1 / IN2 |
| PB0 / PB1 | L298N 右轮 IN3 / IN4 |
| PA6 | L298N 左轮 ENA（PWM） |
| PA7 | L298N 右轮 ENB（PWM） |
| PB5 | HC-SR04 的 TRIG |
| PB6 | HC-SR04 的 ECHO |
| 5V / GND | 所有模块共地 |

> HC-SR04 是 5V 供电，ECHO 输出 5V。STM32F103 的 GPIO 输入口基本都容忍 5V，直接接没事。

## 工作流程

主循环里每隔 50ms 测一次距离：

1. 距离 < 20cm（`AVOID_DISTANCE_CM`）→ 停车，原地左转约 0.4 秒，再停车；
2. 距离 >= 20cm → 直走。

靠这种「遇障左转」的简单策略，在障碍环境里绕行。

## 测距原理

HC-SR04 靠超声波回声测距：

- 给 TRIG 一个 20us 以上的高电平，模块发出 8 个 40kHz 超声波；
- ECHO 拉高，持续时间 = 声波来回的时间；
- 声速约 340m/s，来回除以 2，所以 `距离(cm) = 时间(us) * 0.017`。

代码里用 DWT（`delay.c`）数周期来算微秒，比 `HAL_Delay` 精确（`HAL_Delay` 最小只能 1ms）。

## 调试笔记（踩过的坑）

1. **电机抖动**：L298N 供电不足会导致电机一顿一顿的，电池电压别太低；PWM 频率用 1kHz 左右对 L298N 比较稳（代码里就是这么配的）。
2. **测距一直是 0 或者乱跳**：
   - 先看 ECHO 有没有接对（TRIG/ECHO 别接反）；
   - 检查是否共地；
   - `delay_us` 依赖 DWT，记得 `Delay_Init()` 在 `Ultrasonic_Init()` 里已经调了，别删。
3. **传感器误检**：HC-SR04 在太近（<2cm）或倾斜角大会测不准，属于正常现象。避障阈值别设太小，20cm 比较稳。
4. **车不走直线**：左右电机转速有差异，属于硬件误差。可以微调左右轮的 PWM 值补偿，或者不管它（避障场景影响不大）。
5. **上电乱动**：GPIO 初始化先拉低 IN1~IN4 和 TRIG，避免电平不确定。

## 代码结构

```

Core/Src/motor.c         电机驱动（差速转向）

Core/Src/delay.c         DWT 微秒延时
Core/Src/tim.c           TIM3 两路 PWM（1kHz）
```
