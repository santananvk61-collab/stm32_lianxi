## 3. 踩过的坑 & 修复（按时间顺序，含根因）

### ① SWJ 调试口被关掉 → 烧录后 ST-Link 连不上
- 现象：`No device found on target`。
- 根因：CubeMX SYS→Debug 默认 `No Debug`，生成 `__HAL_AFIO_REMAP_SWJ_DISABLE()`，烧进去后 PA13/PA14 的调试功能被禁用。
- 修复：`stm32f1xx_hal_msp.c` 改为 `__HAL_AFIO_REMAP_SWJ_NOJTAG()`，保留 SWD。
- 救砖：手动按 RESET 配合 Debug；或用 BOOT0 拨 1 进系统 bootloader，用 STM32CubeProgrammer 全片擦除。

### ② PA0 推挽输出 → 与 DHT11 对拉
- 修复：GPIO 模式改为 **Open Drain + Pull-up**。单总线靠「MCU 拉低 = 发 0；松手 = 上拉拉成 1」实现双向通信。

### ③ 系统时钟停在 8MHz 无 PLL
- 修复：`HSE + PLL×9 = 72MHz`。

### ④ APB1 超频（72MHz）
- 现象：APB1 Prescaler 设 /1，PCLK1 = 72MHz，超过 F103 的 36MHz 上限。
- 修复：改为 /2。

### ⑤ 新加的 .c 不进构建（链接报错 undefined reference）
- 根因：CubeIDE 的 make 构建系统不会自动编未列出的源文件。
- 修复：把 `ssd1306.c` / `dht11.c` 加入 `Debug/Core/Src/subdir.mk`（C_SRCS / OBJS / C_DEPS 三处）和 `Debug/objects.list`。
- ⚠️ `Debug/` 被 `.gitignore` 忽略，此改动不进版本库（见第 6 节）。

### ⑥ ST-Link 线无 NRST 脚
- 现象：软件 `Connect under reset` 无效（发复位命令没人收）。
- 处理：手动按板子 RESET 键配合 Debug；或 BOOT0 拨 1 救砖。

### ⑦ SDA 误接到 B5（不是 PB7）
- 现象：I2C 总线无设备，探测代码 LED 常亮不闪。
- 修复：改回 PB7。之后 LED 闪 2 下，确认屏真实地址 **0x3C** 有应答。

### ⑧ 显示发虚
- 根因：对比度 `0xCF` 太亮。
- 修复：降到 `0x7F`。

### ⑨ 拉长 / 颠倒 / 只占半屏
- 根因：128×64 屏的 COM pins 误用 `0x02`（那是 128×32 的值），正确应为 `0x12`。
- 修复：`ssd1306.c` 中 64 行分支 `0xDA, 0x12`。

### ⑩ 字符错乱（真因，降速无效）
- 现象：`TEMP` 显示成 `IFUN`、`HUMI` 显示成 `HNUT`，方向比例都正常。
- 根因：`Font5x7` 字库数据是 **bit0 = 该列最顶行**（标准 5×7 字模，数据本身正确）；但 `SSD1306_WriteChar` 里用 `glyph[col] & (1 << (7 - row))` 把 bit7 当顶行读，导致**每个字上下颠倒**，看起来像别的怪字符。
- 修复：`ssd1306.c` 改为 `glyph[col] & (1 << row)`，并修正注释。
- 结论：字符变形优先查字库位序，与 I2C 速度无关（所以降速没变化）。

## 4. 关键源码文件

- **main.c**：`USER CODE 2` 里 `DHT11_Init()` + `SSD1306_Init()`；`while(1)` 每 2s 调 `DHT11_Read(&temp, &hum)` → 写 `TEMP:`/`HUMI:` → `SSD1306_UpdateScreen()`。
- **dht11.c**：单总线时序（起始信号 19ms → 80µs 应答 → 读 40 位 → 校验和）；用 **DWT 循环计数器**做微秒延时（72MHz 下 1µs = 72 周期），不用粗糙的 `HAL_Delay`。
- **ssd1306.c**：1024 字节显存（framebuffer）+ 标准 5×7 字库 + I2C 发送；`SSD1306_Init` 上电序列、`SetCursor`/`WriteChar`/`WriteString`/`WriteInt`、`UpdateScreen` 整屏一次刷。
