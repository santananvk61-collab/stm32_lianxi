# pwm_project — PWM 脉宽调制

**学什么**：用方波的平均效果调亮度/转速，理解「频率 / 周期 / 占空比」。

## 硬件接线

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA6  | TIM3_CH1 | 接一颗外部 LED（串限流电阻到 GND） |

## 运行现象

PA6 上的 LED 做「呼吸灯」：由暗到亮、再由亮到暗循环。

## 关键知识点

- **频率** = 定时器时钟 / (分频+1) / (周期+1) = 8MHz / 8 / 1000 = **1kHz**。
- **占空比** = 比较值(Pulse) / 周期，改 `__HAL_TIM_SET_COMPARE` 就能调亮度。
- `HAL_TIM_PWM_Start` 一定要调，否则配置了也不出波形。
- `htim3.Init.Prescaler = 7` 表示分频 8（寄存器里存的是 7，实际是 +1）。

## 构建

用 STM32CubeIDE 导入本目录，或用 `arm-none-eabi-gcc` 编译 `Core/`、`Drivers/` 下的源码。
