# onewire_project — 单总线（读取 DHT11 温湿度）

**学什么**：用一根数据线通信，理解「开漏 + 微秒级时序」。

## 硬件接线

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA0  | DHT11 数据脚 | 接 DHT11 的 DATA（建议外接 4.7k 上拉到 3.3V） |
| PC13 | 板载 LED | 状态指示：读到慢闪，读不到快闪 |

## 运行现象

LED 慢闪（约 1 秒周期）= 温湿度读取成功；快闪（约 200ms）= 超时或校验错。

## 关键知识点

- 单总线只有一根数据线，**0 和 1 靠高电平持续多久区分**，所以需要精确的微秒延时。
- 数据脚配成 `GPIO_MODE_OUTPUT_OD`（开漏）+ 上拉：写 0 拉低总线、写 1 松手、读读真实电平。双方都只能拉低，不会短路冲突。
- 微秒延时用内核 **DWT 计数器**实现（`dht11.c` 里 `DWT_DelayUs`），比 `HAL_Delay(1ms)` 精确得多。
- DHT11 返回 5 字节：湿度高、湿度低、温度高、温度低、校验和，校验通过才可信。

## 构建

用 STM32CubeIDE 导入本目录，或用 `arm-none-eabi-gcc` 编译 `Core/`、`Drivers/` 下的源码。
