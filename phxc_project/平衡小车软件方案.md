## 0. 与旧方案的关键差异（先看这段）

| 项 | 旧方案 v1.1（假设） | **实际硬件（本方案）** |
|---|---|---|
| 姿态传感 | QMI8658A @ SPI2 | **ICM-42670-L @ SPI1**：PA5(SCK)/PA6(MISO)/PA7(MOSI)，片选 PA4，中断 PB0 |
| 电机驱动 | TB6612FNG（含 STBY/PWMA/PWMB/AIN/BIN） | **双 AT8236**（单通道 H 桥，**无 STBY**、**nFAULT 未引出**） |
| 电机控制 | TIM3 两路 PWM + 4 路方向 GPIO | **TIM4 CH1~CH4 四路 PWM**（PB6/PB7 = 电机2，PB8/PB9 = 电机1） |
| 编码器 | TIM2(PA0/PA1) + TIM4(PB6/PB7) | **TIM2(PA15/PB3) + TIM3(PB4/PB5)** |
| 电池检测 | ADC1_IN6 = PA6 | **ADC1_IN9 = PB1**（33k/10k 分压 + 10k 串阻，量程 14.19V） |
| 系统时钟 | HSE 25MHz（模板残留） | 板上 **8MHz HSE（X1）**，另有 32.768kHz LSE（X2） |
| 显示/交互 | PC13 LED + OLED 可选 | **无 MCU 可控 LED、无按键**（LED1 仅 3V3 电源指示，SW1 是 NRST） |
| 控制周期 | 5ms | **1ms**（与简历一致：1ms 定周期完成姿态解算与串级 PID） |

> 结论：之前按 MPU6050 / TB6612 写的驱动**全部作废**，须按 ICM-42670-L / AT8236 重写。其余架构（分层、互补滤波、串级 PID、安全状态机、单串口协议）保持不变。

### 2.4 硬件特性对软件的硬性约束

1. **AT8236 无 STBY**：不能像 TB6612 那样靠 STBY 一次性断使能；安全态必须靠**两路输入都写 0**（H 桥滑行）。好在 IN1/IN2 内部下拉，上电默认 0，天然安全。
2. **AT8236 无 nFAULT 引出、ISEN 接地**：**没有硬件过流保护反馈，也没设限流电阻**。堵转/短路只能靠芯片自身过温过流保护 + **软件兜底**（编码器反馈异常、占空比限幅、超时降功率）。
3. **PB3/PB4/PA15 是 JTAG 引脚**：必须把 SWJ 配置改为「Disable JTAG，Enable SWD」，否则编码器引脚不可用（PA13/PA14 的 SWD 保留即可）。
4. **无 MCU 可控 LED、无按键**：状态提示只能走串口/蓝牙；如需可视指示，用预留 PB12/PB13 或 PC13 加灯。
5. **编码器由 5V 供电**：PB4/PB5/PA15/PB3 都是 5V 容忍脚（FT），可直接接；若担心噪声可在信号线上加 100Ω 串阻。
6. **HSE 是 8MHz**：CubeMX 时钟树必须把 PLL 源改为 HSE（不能沿用模板里的 HSI 或 25MHz）。

## 4. 软件架构

### 4.1 总体形态

裸机超循环（`while(1)` + 时间片标志），**不使用 RTOS**。1ms 控制链 + 慢速任务分离。

### 4.2 分层与文件清单

```
App/                                   ← 自研代码，与 CubeMX 生成代码隔离
├── bsp_spi_icm42670.c/.h              驱动层：SPI1 寄存器读写(bit7=R/W)、BANK 切换、
│                                      WHO_AM_I 校验、初始化、原始值→物理量换算
├── bsp_at8236.c/.h                    驱动层：有符号占空比→IN1/IN2 两路 PWM 映射、
│                                      H 桥真值表、滑行/制动、急停
├── bsp_encoder.c/.h                   驱动层：编码器计数→速度（四倍频）、方向符号、回绕处理
├── bsp_adc_vbat.c/.h                  驱动层：ADC1_IN9 采样、滑动平均、电压换算
├── bsp_uart.c/.h                      驱动层：USART1 收发、printf 重定向、中断收帧
├── attitude.c/.h                      算法层：陀螺零偏校准 + 互补滤波（姿态唯一出口）
├── pid.c/.h                           算法层：通用 PID（输出限幅 + 积分抗饱和）
├── balance.c/.h                       控制层：串级 PID + 安全状态机（核心）
└── protocol.c/.h                      控制层：串口行指令解析 + 波形打包
Core/Src/main.c                        应用层：外设初始化 + 时间片调度
```

**分层规则**：驱动层只碰硬件；算法层只算数据；控制层只做决策；`main` 只做初始化与调度。上层不感知总线类型（换 IMU 只改驱动层）。

## 5. 驱动层设计要点

### 5.1 ICM-42670-L（SPI1）

- **读协议**：首字节 = `0x80 | 寄存器地址`（bit7=1 读），随后再发 1 个字节（dummy）收回数据，MSB 先出；**写**：首字节 = 地址(bit7=0) + 数据字节。
- **寄存器组切换**：`BANK_SEL (0x76)`；配置与数据均在 Bank 0。
- **上电校验**：读 `WHO_AM_I (0x75)`，期望值以你手上 datasheet 为准（ICM-42670-L/P 通常 **0x67**），**S1 实测确认后固化为宏** —— 这是 IMU 健康标志。
- **初始化（Bank 0，地址以 datasheet 为准）**：
  - `PWR_MGMT0 (0x4E)`：使能加速度计 + 陀螺仪（低噪声模式）
  - `GYRO_CONFIG0 (0x4F)`：ODR 与满量程（建议 ODR ≥ 1kHz、FS ±500 dps）
  - `ACCEL_CONFIG0 (0x50)`：ODR 与满量程（建议 ODR ≥ 1kHz、FS ±4g）
  - `INT_CONFIG (0x63)` / `INT_SOURCE0 (0x65)`：若用 PB0 中断则配数据就绪
- **数据读取**：`GYRO_DATA_X1 (0x0B)` 起 6 字节；`ACCEL_DATA_X1 (0x1F)` 起 6 字节；小端 int16 合成，再乘 sensitivity（±4g→8192 LSB/g，±500dps→65.5 LSB/(°/s)，**以 datasheet sensitivity 表核对**）。
- 驱动封装 `icm_read_reg / icm_write_reg / icm_read_burst`，上层只拿物理量。
- 采样：1ms 轮询（先不用 INT，S7 再考虑）。

### 5.2 AT8236（TIM4 四路 PWM）

**H 桥真值表**（AT8236 兼容 DRV8870/A4950，TI 明文给出）：

| IN1 | IN2 | OUT1 | OUT2 | 状态 |
|---|---|---|---|---|
| 0 | 0 | 高阻 | 高阻 | **滑行 Coast** |
| 1 | 0 | H | L | **正转**（电流 OUT1→OUT2） |
| 0 | 1 | L | H | **反转** |
| 1 | 1 | L | L | **制动 Brake**（低边慢衰减） |

**软件映射**（有符号占空比 `d ∈ [-1, +1]` → 两路 PWM）：

```
d > 0 :  IN1 = PWM(d)      IN2 = 0          // 正转
d < 0 :  IN1 = 0           IN2 = PWM(-d)    // 反转
d = 0 :  IN1 = 0           IN2 = 0          // 滑行（默认安全态）
需要主动刹车时：IN1 = IN2 = 1               // 转向/急停可选
```

- 引脚归属：电机1 = U5（IN2=PB8/TIM4_CH3, IN1=PB9/TIM4_CH4）；电机2 = U6（IN2=PB6/TIM4_CH1, IN1=PB7/TIM4_CH2）。
- 上电/复位默认 H 桥输入全 0（内部下拉）→ 滑行，**安全**；初始化仍显式写 0。
- **无 STBY**：急停只能靠写 0；若要"真正断电"需外部继电器（本板没有）。
- **无硬件限流**：占空比斜坡限幅 + 堵转检测（见 §8）。

### 5.3 编码器（TIM2 / TIM3）

- 硬件**四倍频**（TI1&TI2），Period=65535，Input Filter≈10 抗电机噪声。
- 每周期读计数差：`int16_t delta = (int16_t)(now - last)`（利用 16 位回绕自然处理）。
- **方向符号实测标定**（`s_enc_dir[2]` 宏修正）：正转时计数应递增。
- 速度 = Δ计数 / (减速比 × 线数 × 4) × 轮周长 / Δt；机械参数（减速比、编码器线数、轮径）做成宏，S1 前先测出来填。

### 5.4 电池电压（ADC1_IN9 = PB1）

- 单次转换、12bit、Vref 3.3V、**采样时间 84 Cycles**（源阻抗 17.7kΩ，见简历）。
- 分压比：`Vbat = adc × 3.3 / 4095 × (33+10) / 10`，**量程 14.19V**（3S 锂电 12.6V 满、9.0V 亏）。
- 软件侧滑动平均 + 一阶滤波；低压阈值：<9.9V 提示、<9.0V 告警停车。

### 5.5 串口 / 蓝牙（USART1）

- 单串口**同时**做调试与遥控；蓝牙模块插 U7 座（PA9↔BT.RX、PA10↔BT.TX）。
- 帧格式：以 `\n` 结尾的 ASCII 行；中断收字节 → 组帧 → 交 `protocol.c` 解析。
- 上行：50ms 一次波形（FireWater 文本格式）+ 状态文本（`printf` 重定向到 USART1）。

## 6. 核心算法

### 6.1 姿态解算（互补滤波）

```
pitch = α × (pitch + gyro × dt) + (1 − α) × accel_angle
```

- `dt = 0.001s`（1ms 定周期）；α 起步 0.985~0.995
- `accel_angle = atan2f(...)`（M4F 硬件 FPU 直接用），**用哪两轴由安装方向实测确定**
- **开机零偏校准**：静止采集 1500+ 样本取均值作为陀螺零偏；校准期间电机保持滑行；车体必须静止直立
- 校准时同时可估计加速度零偏（可选）

### 6.2 串级 PID

```
编码器速度 → 速度环 PI → 目标角修正 → 角度环 PD → 基础PWM ┬→ 电机1 = 基础 + 转向
   (遥控目标速度)↑              ↑                          └→ 电机2 = 基础 − 转向
                          pitch + 陀螺仪俯仰角速度

转向量 = Kturn × 陀螺仪Z轴角速度（直行阻尼） + 遥控差速
```

| 环 | 类型 | 周期 | 要点 |
|---|---|---|---|
| 角度环（内环） | **PD** | 1ms | D 项**直接用陀螺仪角速度**，不做角度差分 |
| 速度环（外环） | **PI** | 5ms（1ms 内分频触发） | 输出为目标角修正（想前进则小幅前倾）；积分限幅 + 抗饱和 |
| 转向环 | P 为主 | 1ms | Z 轴陀螺阻尼防跑偏；遥控时叠加差速 |

**输出限幅 ±ARRAY(4199)** = PWM 量程 = TIM4 ARR，控制限幅与驱动限幅一致。

**符号约定在驱动层统一闭合**：电机正转方向、编码器正向、pitch 前倾为正 —— S1 用固定占空比点动逐一实测；符号错了任何 PID 都救不回来。

### 6.3 三个"偏移量"严格分开（调参纪律）

| 变量 | 含义 | 确定方式 |
|---|---|---|
| `gyro_offset` | 陀螺零偏 | **开机自动校准，不手填** |
| `mech_angle` | 机械中值角（车直立时 pitch） | 标定阶段实测，填一次宏 |
| `target_angle` | 目标角偏置 | **速度环自动产生，不手调** |

## 7. 控制框架与任务调度

| 周期 | 任务 | 执行位置 |
|---|---|---|
| **1ms** | 读 IMU(SPI) → 互补滤波 → 角度环 PD →（每 5ms 触发速度环 PI）→ 写 TIM4 CCR | **TIM5 中断内**（SPI 轮询约 10~20µs，预算充裕，抖动最小） |
| 20ms | 安全状态机、低压判断 | 主循环时间片 |
| 50ms | 波形打包上传 + 状态文本 | 主循环时间片 |
| 100ms | 电池 ADC 采样滤波 | 主循环时间片 |

> 原则：**耗时/不确定操作（printf、波形、蓝牙解析、ADC、状态机）一律移出中断**；中断内只做确定性、短耗时的控制链。
> 若实测中断内 SPI 抖动偏大，退化方案：中断只置 `g_tick_1ms` 标志，控制链搬到主循环（与旧方案一致）。

## 8. 安全机制（优先级最高）

1. **上电安全态**：H 桥输入全 0（滑行）；仅当「WHO_AM_I 正常 + 零偏校准完成 + 姿态在直立范围内 + 使能」才进入闭环
2. **摔倒保护**：每周期入口判断 `|pitch| > 40°` → 立即 PWM=0、停 PID、**清速度环积分**（防恢复瞬间猛冲）
3. **传感器看门狗**：连续 N 周期读不到有效 IMU 数据（或 WHO_AM_I 异常）→ 按摔倒处理
4. **堵转兜底**：占空比大而编码器长时间无变化 → 降功率/停机（本板无硬件限流，这层必须有）
5. **限幅一致**：控制输出限幅 = PWM 量程；上电/恢复做占空比斜坡，杜绝突转
6. **低压保护**：ADC 检测 12V，单节 <3.0V（总 9.0V）告警停车

**状态机**：`CAL → READY → RUN → FALL/FAULT`；退出 FALL 需重新摆正 + 重新使能。

## 11. 调参指南

**顺序**：角度环 Kp 从小加到轻微振荡 → 加 Kd 压住 → 速度环（比角度环慢）先 P 后 I，I 最后小量加。**每个阶段只动一个环。**

| 现象 | 先查 |
|---|---|
| 上电立刻倒 | 电机方向符号 / 角度环方向 |
| 高频抖动 | Kp 过大 / IMU 振动噪声 / dt 不一致 |
| 慢速遛走 | 没接速度环（S3 阶段正常） |
| 一冲一冲 | 积分饱和 / 符号不一致 |
| 侧翻 | 中值角没标定 / IMU 安装轴不对 |
| 只朝一侧加速 | 编码器方向符号 / 转向环符号 |

**纪律**：只改 §6.3 中对应的那一个偏移量；不凭感觉批量改参；出问题先按上表定位环节。

## 12. 风险与待确认项（S1 必须闭环）

| # | 待确认 | 说明 |
|---|---|---|
| 1 | `WHO_AM_I` 期望值 | 常见 0x67；以 datasheet 为准，实测后固化为宏 |
| 2 | SPI 模式 | Mode 0 或 3；读到正确 WHO_AM_I 即为配对 |
| 3 | 电机极性 | IN1/IN2 ↔ 车轮正反转；实测定符号 |
| 4 | 编码器极性 | 计数方向 vs 车轮方向 |
| 5 | IMU 轴对齐 | 哪两轴算 pitch；X 轴应对齐车前进方向 |
| 6 | 机械参数 | 减速比 / 编码器线数 / 轮径（算真实速度） |
| 7 | 编码器 5V 电平 | PB4/PB5/PA15/PB3 是 FT 脚，可用；必要时加串阻 |
| 8 | 无硬件限流 | 堵转/短路靠芯片自保护 + 软件兜底，测试时先小占空比 |
| 9 | 时钟树 | 必须改 HSE=8MHz，否则串口波特率与 1ms 全偏 |
| 10 | JTAG 释放 | 不关 JTAG，PA15/PB3/PB4 无法用作编码器 |

## 附录 C：网表提取方法（可复现）

`schematic (.esch2)` 与 `pcb (.epcb2)` 都是嘉立创EDA专业版的**逐行 JSON 记录**（每行 `{header}||{payload}`）。PCB 中的 `PAD_NET` 记录其 `id` 形如 `["PAD_NET", 元件ID, 焊盘号, 焊盘ID]`，`padNet` 即网络名；元件位号来自 `ATTR(key="Designator", parentId=元件ID)`。据此可直接导出"位号.焊盘 → 网络"的完整网表，本方案第 2 节即由该方法提取。
