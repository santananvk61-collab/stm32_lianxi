# onewire_project

一根线读 DHT11 温湿度。这个时序最磨人，0 和 1 全靠高电平持续时间区分，必须微秒级延时。

- `HAL_Delay` 只有毫秒，不够用，改用 DWT 内核计数器写了 `Dht11_DelayUs`（dht11.c）。
- 数据脚配开漏 + 上拉：写 0 拉低、写 1 松手、读之前也要松手，不然读回来的全是自己。
- DHT11 回 5 字节，最后一个是校验和，加起来对不上就整个丢掉重读。
- 读不到的坑：延时差几微秒就全 0xFF，后来 LED 快闪=失败、慢闪=成功，肉眼好判断。

接线：PA0 接 DHT11 DATA（最好外接 4.7k 上拉到 3.3V）。
