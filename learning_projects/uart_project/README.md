# uart_project — UART 串口通信

**学什么**：让 MCU 和电脑互相「说话」，这是最常用的调试手段。

## 硬件接线

| 引脚 | 功能 | 说明 |
|------|------|------|
| PA2  | USART2_TX | 接 USB 转串口的 RX |
| PA3  | USART2_RX | 接 USB 转串口的 TX |

## 运行现象

打开串口助手（**115200，8 数据位，无校验，1 停止位**），上电看到一句欢迎语；敲任意字符会原样回显。

## 关键知识点

- 收发双方**波特率、数据位、校验、停止位**必须一致，否则乱码。
- `HAL_UART_Receive` 是阻塞的：一直等到收到数据才返回。
- 发送用 `HAL_UART_Transmit`，参数是「句柄、数据指针、字节数、超时」。
- PA2 配成 `GPIO_MODE_AF_PP`（复用推挽），PA3 配成输入。

## 构建

用 STM32CubeIDE 导入本目录，或用 `arm-none-eabi-gcc` 编译 `Core/`、`Drivers/` 下的源码。
