# iwdg_project

独立看门狗。1 秒超时，主循环 100ms 喂一次，LED 一直闪 = 程序活着。

上电先闪 3 下再进主循环，是有意的"开机指纹"——被狗咬了复位也会重新走这 3 下，肉眼就能分辨板子是不是刚被复位过。

试过把 `HAL_IWDG_Refresh` 注释掉再烧：变成"3 连闪 → 闪一小会 → 又 3 连闪"无限循环，狗真的咬了。

记几个点：

- 超时 ≈ (Reload + 1) × 预分频 ÷ 40000，我这里 32 分频 + 1250 ≈ 1 秒。
- 独立 = 跑在 LSI（约 40kHz）上，主时钟挂了它照样数数。
- LSI 手册写 30~60kHz，根本不准，所以只能当保底复位用，别指望它定时。
- 启动之后关不掉，只能喂或者等复位，所以初始化放最后。
- 调试时断点停住狗还在数——CubeIDE 的 Debug Configurations 里可以把 watchdog freeze 掉，不然一打断点就复位。
