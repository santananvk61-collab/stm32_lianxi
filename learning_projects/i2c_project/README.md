# i2c_project

两根线（PB6=SCL，PB7=SDA）点了一块 0.96 寸 SSD1306 OLED，显示计数器。

- OLED 地址 0x3C，搜代码的时候见过 0x78 的，那是带了读写位的写法，坑过。
- 引脚配 `GPIO_MODE_AF_OD` 开漏，靠上拉电阻出高电平。
- 驱动分了层：main.c 只管"显示什么"，ssd1306.c 翻译成 I2C 字节，最底下才是 HAL。第一次自己分层，写乱了两次。
- 便宜模块 400kHz 会跑飞，降到 100kHz 就稳了（后来 OLED 大项目里也复现过一次）。
- OLED 按"页"组织，8 行像素压 1 字节，整屏 1024 字节，改完一起刷。
